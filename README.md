## 💻 How to Run Locally

Simply clone the repository and launch in any browser:

```bash
# 1. Clone the repository
git clone https://github.com/chandana-agm/cportfolio.git

# 2. Open the directory
cd cportfolio

# 3. Open directly in your browser:
# On Windows:
start index.html

# Or run using Node.js / Python
node server.js
# Open http://localhost:8080 in your browser
```
